# Knowledge base for "Ask Cat"

Sample manual content written for this prototype. A production system would use official Cat
Operation & Maintenance Manuals. Nothing here is copied from a manufacturer's manual.

Each file starts with front matter: `id`, `title` (en/hi/ta), `machine_types` (or `all`) and
`section`. English files are `<id>.md`; key safety files also have `<id>.hi.md` and `<id>.ta.md`
with the same headings in the same order, so chunk `<id>#<n>` means the same passage in every
language. Build the index with `shiftmate assistant index`.
